# Contributing

Use the pinned package manager and lockfile. Run check, test, build and verify:package before submitting a change. Commit regenerated lib files with source changes so Git installation does not need an install-time build.

Keep the sidebar read-only, compact and compatible with unmodified producers. Never derive an actor merely from source-tag names or message text. Changes to collection must preserve original message identity, return/Promise/error behavior, scope resolution and teardown. Prefer bounded observation to background polling or invasive instrumentation.

Tests and issue reports must use synthetic content. Do not attach credentials, login URLs, real session logs, private paths or unredacted screenshots. Describe exact host/plugin versions and distinguish observed evidence from inference. UI language work is welcome; the current interface is primarily Chinese.
