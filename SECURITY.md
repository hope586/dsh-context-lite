# Security and privacy

This is a same-process DSH plugin, not a security boundary or an independently audited product. Install only code you trust. It reads host-accessible sessions and stores bounded provenance metadata; see README and docs/provenance.md.

Do not include credentials, authentication links, real conversation bodies, private paths or unredacted screenshots in public issues. Use GitHub's private vulnerability reporting when available for sensitive reports. If unavailable, open a minimal issue asking for a private reporting channel without disclosing the sensitive details.

General compatibility bugs may be reported publicly with synthetic reproduction steps and exact versions. Only the versions listed in docs/compatibility.md have direct acceptance evidence. Uninstalling does not delete host sessions or the plugin's prior metadata.
